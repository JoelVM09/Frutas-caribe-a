### 📝 Descripción del Proyecto
Este proyecto es una web interactiva y moderna diseñada para destacar e informar sobre tres frutas caribeñas esenciales. La aplicación combina un enfoque científico, cultural y de salud mediante una interfaz fluida organizada por pestañas explicativas y filtros por temporada.

---

### 🛠️ Tecnologías Usadas
* **React** (Biblioteca principal de JavaScript para la interfaz)
* **Vite** (Entorno de desarrollo rápido y empaquetador)
* **Context API** (Para la persistencia y gestión del estado global)
* **JavaScript (ES6+) / JSX** (Lenguaje de programación)
* **CSS3** (Estilos modernos, diseño adaptivo y pestañas interactivas)

---

### 🧠 Qué Aprendimos
Durante el desarrollo de este reto, nuestro equipo consolidó los siguientes conocimientos:
1. **Gestión de Estado Global:** Implementación de `Context API` de React para evitar el traspaso manual de propiedades (*prop drilling*) al gestionar las frutas y filtros.
2. **Arquitectura de Componentes:** Organización eficiente y limpia de archivos y componentes modulares en React.
3. **Integración Multidisciplinaria:** Capacidad de estructurar datos que combinan ciencia, cultura y salud dentro de una misma experiencia de usuario.
4. **Herramientas de Desarrollo:** Configuración y uso manual del entorno local mediante Node.js y Vite.
